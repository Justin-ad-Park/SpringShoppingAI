# 07 보충 1. 기본 시스템 메시지와 메시지 창

이 문서는 시스템 메시지의 기본값을 설정하는 방법과, 대화가 길어질 때 어떤 메시지를 남기는지 설명합니다.<br>
03단원의 프롬프트 구성과 07단원의 대화 메모리를 배운 뒤 읽습니다.<br>
예제는 Spring AI 2.0.2를 기준으로 합니다.

## 1. 모든 요청에 같은 응답 원칙을 적용하려면

시스템 메시지(`system`)는 애플리케이션이 모델에 전달하는 역할이나 응답 원칙입니다.<br>
예를 들어 “쉬운 영어로 답하세요.”라는 지시를 여러 질문에 공통으로 사용하려면, ChatClient를 만들 때 `defaultSystem(...)`으로 설정할 수 있습니다.

| 메서드 | 언제 설정하나요? | 어떤 요청에 적용되나요? |
|---|---|---|
| `defaultSystem(...)` | Builder로 ChatClient를 만들 때 | 이 ChatClient의 요청에서 사용할 기본 시스템 메시지 |
| `system(...)` | `chatClient.prompt()`로 요청을 구성할 때 | 이번 요청에 적용하며 기본값이 있으면 대신 사용 |

### 기본값 사용 → 이번 요청에서 변경 → 다시 기본값 사용

아래는 Spring이 주입한 `ChatClient.Builder builder`를 사용하는 코드입니다.<br>
생성자와 import는 생략했으며, `ChatClient`의 import는 `org.springframework.ai.chat.client.ChatClient`입니다.<br>
실제 모델에 연결해 실행하면 세 번의 요청에 대한 API 사용량이 발생합니다.

먼저 기본 시스템 메시지를 설정하고 질문합니다.

```java
ChatClient chatClient = builder
        .defaultSystem("쉬운 영어로 답하세요.")
        .build();

String firstAnswer = chatClient
        .prompt()
        .user("Spring AI가 뭐야?")
        .call()
        .content();

System.out.println(firstAnswer);
```

이번 요청에는 기본값인 **“쉬운 영어로 답하세요.”**가 시스템 메시지로 전달됩니다.

같은 ChatClient를 사용하되, 두 번째 요청에는 별도의 시스템 메시지를 지정합니다.

```java
String secondAnswer = chatClient
        .prompt()
        .system("쉬운 한국어로 답하세요.")
        .user("Spring AI가 뭐야?")
        .call()
        .content();

System.out.println(secondAnswer);
```

이번에는 **“쉬운 한국어로 답하세요.”**가 기본 메시지를 대체합니다.<br>
영어 지시와 한국어 지시가 함께 추가되는 것은 아닙니다.<br>
두 언어로 답변받고 싶다면 `.system("쉬운 영어로 답하고, 쉬운 한국어 답변도 추가하세요.")`처럼 필요한 지시를 함께 작성합니다.

세 번째 요청에서는 `system(...)`을 생략합니다.

```java
String thirdAnswer = chatClient
        .prompt()
        .user("Spring AI가 뭐야?")
        .call()
        .content();

System.out.println(thirdAnswer);
```

두 번째 요청의 설정은 ChatClient의 기본값을 바꾸지 않았으므로 다시 영어 지시를 사용합니다.

| 요청 | 요청의 `system(...)` | 모델에 전달되는 시스템 메시지 |
|---|---|---|
| 첫 번째 | 생략 | 쉬운 영어로 답하세요. |
| 두 번째 | 쉬운 한국어로 답하세요. | 쉬운 한국어로 답하세요. |
| 세 번째 | 생략 | 쉬운 영어로 답하세요. |

이 표는 **모델에 전달하는 지시**를 보여줍니다.<br>
모델이 실제로 지시한 언어로 답했는지는 응답을 읽어 확인합니다.<br>
API 키 없이 전달된 메시지를 확인하려면 기존 [SystemMessageDefaultsLocalModelTest](../../labs/02-00-first-chat/src/test/java/com/example/ailearning/l03prompts/SystemMessageDefaultsLocalModelTest.java)를 실행합니다.<br>
이 테스트는 로컬 고정 응답 서버에 전송된 시스템 메시지가 영어 → 한국어 → 영어 지시인지 검증합니다.

```bash
./gradlew :Spring-AI-Agent-Learning:labs:02-00-first-chat:test --tests 'com.example.ailearning.l03prompts.SystemMessageDefaultsLocalModelTest'
```

위 명령은 저장소 루트에서 실행하며 실제 OpenAI를 호출하지 않습니다.

## 2. 메시지 창은 어떤 대화를 남길까?

**메시지 창**은 이전 대화 중 최근 메시지를 일정 개수까지 보관하는 방식입니다.<br>
Spring AI의 `MessageWindowChatMemory`가 이 역할을 합니다.<br>
`maxMessages(6)`은 **대화 ID 하나마다 보관할 메시지 수를 최대 6개로 제한**한다는 뜻입니다.

| 구분 | 이 예제에서 뜻하는 것 |
|---|---|
| 메시지 1개 | 사용자 질문 하나 또는 모델 답변 하나 |
| 질문·답변 한 쌍 | 메시지 2개 |
| `maxMessages(6)` | 메시지 수 상한 6개. 항상 6개를 채운다는 뜻은 아님 |

따라서 system 메시지 없이 질문과 답변만 보관한다면, 질문·답변 세 쌍이 메시지 6개입니다.<br>
사용자 수나 토큰 수를 제한하는 설정은 아닙니다.<br>
`maxMessages`를 생략하면 기본값은 20개이며, 이 예제는 변화를 확인하기 쉽게 6개로 지정했습니다.

### 왜 7개에서 6개가 아니라 5개로 줄어들까?

메시지가 상한을 넘으면 오래된 메시지를 제거합니다.<br>
이때 질문을 지운 뒤 그 질문의 답변만 남지 않도록, 남길 일반 대화가 사용자 질문(`user`)부터 시작하게 정리합니다.

| 단계 | 보관되는 메시지 | 개수 |
|---|---|---:|
| 질문·답변 세 쌍 저장 | 질문1, 답변1, 질문2, 답변2, 질문3, 답변3 | 6 |
| 질문4 추가 시 정리 전 목록 | 질문1, 답변1, 질문2, 답변2, 질문3, 답변3, 질문4 | 7 |
| 질문4의 `add(...)` 완료 후 | 질문2, 답변2, 질문3, 답변3, 질문4 | 5 |
| 답변4의 `add(...)` 완료 후 | 질문2, 답변2, 질문3, 답변3, 질문4, 답변4 | 6 |

질문1만 지우면 목록이 답변1부터 시작합니다.<br>
`MessageWindowChatMemory`는 답변1도 함께 제거하므로 질문4를 추가한 직후에는 5개가 남습니다.<br>
정리 전의 7개 목록은 처리 과정을 설명한 것이며, `get(...)`으로 조회할 때는 이미 정리된 5개가 반환됩니다.

### 모델을 호출하지 않고 확인하기

아래는 `main()`으로 실행할 수 있는 전체 예제입니다.<br>
`07-00-chat-memory` 실습의 의존성을 사용하는 Java 클래스에서 실행할 수 있으며, 외부 모델이나 API 키는 필요하지 않습니다.<br>
`AssistantMessage`에는 동작을 비교하기 위한 예시 답변을 직접 넣었습니다.

```java
import java.util.List;

import org.springframework.ai.chat.memory.ChatMemory;
import org.springframework.ai.chat.memory.MessageWindowChatMemory;
import org.springframework.ai.chat.messages.AssistantMessage;
import org.springframework.ai.chat.messages.Message;
import org.springframework.ai.chat.messages.UserMessage;

public class MessageWindowExample {
    public static void main(String[] args) {
        ChatMemory memory = MessageWindowChatMemory
                .builder()
                .maxMessages(6)
                .build();
        String conversationId = "message-window-example";

        memory.add(conversationId, List.of(
                new UserMessage("질문1"),
                new AssistantMessage("답변1"),
                new UserMessage("질문2"),
                new AssistantMessage("답변2"),
                new UserMessage("질문3"),
                new AssistantMessage("답변3")));
        printMessages("처음 저장", memory.get(conversationId));

        memory.add(conversationId, new UserMessage("질문4"));
        printMessages("질문4 추가 후", memory.get(conversationId));

        memory.add(conversationId, new AssistantMessage("답변4"));
        printMessages("답변4 추가 후", memory.get(conversationId));
    }

    private static void printMessages(String label, List<Message> messages) {
        System.out.printf("%s: %d개%n", label, messages.size());
        for (Message message : messages) {
            System.out.println(message.getText());
        }
        System.out.println();
    }
}
```

출력에서 다음 차이를 확인합니다.

```text
처음 저장: 6개
질문1
답변1
질문2
답변2
질문3
답변3

질문4 추가 후: 5개
질문2
답변2
질문3
답변3
질문4

답변4 추가 후: 6개
질문2
답변2
질문3
답변3
질문4
답변4
```

이 예제는 질문과 답변을 **따로** 추가해 중간 상태를 확인합니다.<br>
기존 07단원의 서비스는 정상 답변을 받은 뒤 질문·답변을 **함께** 저장하므로, 저장 시점에는 새 질문과 답변이 모두 포함됩니다.<br>
메모리에서 조회한 이전 대화를 다음 프롬프트에 넣는 과정은 여전히 애플리케이션이 처리해야 합니다.

## 확인 질문

1. 기본값이 영어 지시인 ChatClient에서 한 요청에만 한국어 `system(...)`을 지정했습니다.<br>
   다음 요청에서 생략하면 어떤 지시를 사용하나요?
2. 위 예제에서 `maxMessages(6)`인데 질문4를 추가한 직후 메시지가 5개인 이유는 무엇인가요?

<details>
<summary>해설</summary>

1. 다시 영어 지시를 사용합니다.<br>
   요청의 `system(...)`은 이번 요청의 메시지를 대체하며 ChatClient의 기본값을 바꾸지 않습니다.
2. 오래된 질문1을 지운 뒤 답변1만 남지 않도록 답변1도 지우기 때문입니다.<br>
   남은 목록은 질문2부터 시작하며, 6은 반드시 채울 개수가 아니라 보관할 수 있는 최대 개수입니다.
