# 교육 계획

## 대상과 목표

선수 지식은 Java 클래스·생성자, Spring DI, 간단한 REST Controller와 Service입니다.
Java record, Reactor, Vector DB, LLM API, Agent 프레임워크 경험은 가정하지 않습니다.
필요한 개념은 해당 수업에서 먼저 설명합니다.

최종 결과물은 가상 상품 검색, 배송비 조회, 반품 규정 검색, 후속 질문을 처리하는 쇼핑 상담 Agent입니다.
금액 계산과 권한 검사는 Java 코드가 담당하고, 모델이 맡는 판단 범위를 설명할 수 있어야 합니다.

## 교재 작성 원칙

1. 한 수업에 주요 새 개념 하나를 도입합니다. 새 용어는 코드보다 먼저 정의합니다.
2. 문제 → 익숙한 Spring 구조 → 새 개념 → 전체 최소 코드 → 실행 → 결과 해석 순으로 설명합니다.
3. 코드에는 import·설정·실행 위치를 포함합니다. 처음부터 프런트엔드나 공통 추상화는 추가하지 않습니다.
4. 정상 동작 뒤에 코드/입력 하나만 바꾸는 실험과 실패 사례를 둡니다.
5. 문장 암기 대신 “누가 결정하고 어디서 실행하는가?”를 설명하게 합니다.
6. 가짜 모델 테스트, 실제 모델 실험, 아직 구현하지 않은 기능을 명시합니다.
7. 외부 자료는 보충 읽기입니다. 한국어 교재만으로 기본 실습을 따라갈 수 있게 합니다.

## 한 단원을 작은 수업으로 읽기

[학습 방법](learning-guide.md)을 기준으로 각 단원의 목차에서 소수업에 들어갑니다.
04장은 한 문서에서 기초 용어·전체 코드·값 검증을 연결해 읽습니다. 05~13은 각 단원의 목차에서 해당 실습 모듈과 소수업 순서를 확인합니다.
02장의 첫 호출 뒤 모델 요청 타임아웃·재시도를, 05장의 도구 호출 뒤 도구 실행 횟수 제한을 별도 보충 모듈로 선택해 학습합니다. 12장에서는 같은 테스트와 결과를 실패 평가·관측에 다시 활용합니다.

## 설명 수업과 실행 모듈의 대응

실행 모듈 앞의 숫자는 연결된 본 단원 번호입니다. 02장의 기본 실습은 `02-00-first-chat`, 선택 보충은 `02-04-multiple-models`입니다.
하위 설명 파일의 `01`·`02`·`03`·`04`는 그 단원 안에서의 읽기 순서이며 실행 모듈 번호와는 구분합니다.

| 설명 수업 | 실행 모듈 | 함께 제공하는 코드와 테스트 |
|---|---|---|
| 01 환경 준비·02 첫 호출·03 프롬프트 실험 | `02-00-first-chat` | 첫 호출 애플리케이션, 로컬 Mock 테스트, 실제 OpenAI 테스트 |

| 04장 본문·05~13의 기본 소수업 | 기존 번호의 labs 모듈 | 기존 애플리케이션·설정·계약 테스트 유지 |

하나의 기능을 나눠 설명하는 수업끼리는 완성된 실행 모듈을 공유합니다.
기능이 다른 추가 실습은 패키지·의존성·포트를 분리하고, 앞 단원 서비스를 호출하거나 미래 단원의 클래스를 import하지 않습니다.
단원마다 test와 bootJar 검증 후 커밋합니다. 실습용 가짜 HTTP 모델은 [공통 test-support](../test-support/README.md)가 제공합니다. 실습은 테스트 의존성으로만 사용하며 다른 단원의 실행 코드를 가져오지 않습니다.

Workflow와 Agent는 같은 상품 검색·배송비 조회 도구로 비교합니다.
비교 요청, 프롬프트, 실습 순서와 완료 질문은 [06장 Workflow와 Agent](lessons/06-workflow-agent.md#workflow와-agent-비교-수업)에서 확인하세요.

## 구현 범위와 선택 심화

04~13은 각각 독립 실행 가능한 모듈로 구현했습니다. 07은 이전 메시지를 직접 조립하며 아직 Advisor를 사용하지 않습니다.
08 Advisor → 09 임베딩과 검색 → 10 RAG → 11 MCP → 12 평가 → 13 통합 순서로 확장합니다.
단원마다 구현·테스트·커밋을 마친 뒤 다음으로 넘어갔습니다.
그림은 [다이어그램 공통 기준](diagram-guide.md)을 적용하고, 앞으로 배울 코드에 의존하지 않습니다.

11장은 기존 shopping-mcp를 사용해 원격 도구 연결을 학습합니다. 기초 실습은 이전처럼 다른 서비스를 실행하지 않고 학습할 수 있으며, 11장 로컬 테스트는 MCP 서버를 자동 실행합니다.
멀티 에이전트·Skills·A2A, 외부 Vector DB, 스트리밍 UI, 이미지/음성은 필수 과정 이후로 미룹니다.
RAG나 MCP가 있어야만 Agent를 만들 수 있는 것은 아닙니다.
