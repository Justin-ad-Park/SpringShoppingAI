# Mock 데이터와 범용 MCP 도구

## 장바구니 fixture

| scenario | 내용 | 합계 |
|---|---|---:|
| standard | 그래놀라 18,000원 × 1 + 오트 밀크 12,000원 × 2 | 42,000원 |
| already-free | 그래놀라 × 2 + 오트 밀크 × 2 | 60,000원 |
| empty | 없음 | 0원 |
| no-match | 샘플 비스킷 × 1 | 1,000원 |

데이터는 `MockShoppingStore`의 불변 메모리 객체입니다. DB가 필요하지 않습니다.
scenario는 장바구니 fixture 선택용이며 범용 상품 검색 인자가 아닙니다.

## MCP 계약 (한 서버, 여섯 도구)

| 도구 | 입력 | 책임 |
|---|---|---|
| searchProducts | query 객체 | 범용 상품 검색 |
| getCart | scenario | 고정 고객 장바구니 조회 |
| getShippingPolicy | 없음 | 실제 배송 정책 조회 |
| quoteCart | scenario, additionalProductIds | 추가 상품의 가상 장바구니 금액/배송비 |
| getCoupons | 없음 | 웰컴 쿠폰 2,000원 / 최소 구매 30,000원 |
| getPoints | 없음 | 적립금 3,500원 |

기존 calculateShippingGap/quoteAdditionalProduct 도구는 제거했습니다.
차액과 추천 상한은 Agent 업무에서 계산하고, 배송비는 quoteCart가 계산합니다.
quoteCart는 추가 상품 목록을 각 1개씩 합산합니다. 실제 장바구니는 변경하지 않습니다.
Mock 견적은 동일 배송그룹만 지원하며 다른 그룹/품절이면 valid=false입니다.
견적 자체에는 추천 예산이나 이미 장바구니에 있는 상품 제외 정책이 없습니다.

범용 검색 입력 예:

```json
{
  "query": {
    "keyword": "텀블러",
    "minPrice": 0,
    "maxPrice": 30000,
    "category": null,
    "excludeProductIds": [],
    "shippingGroups": [],
    "inStockOnly": true,
    "sort": "PRICE_ASC",
    "limit": 20
  }
}
```

가격은 양 끝 포함. minPrice 생략은 0, maxPrice 생략은 상한 없음입니다.
정렬 PRICE_ASC/PRICE_DESC, limit 기본 20/최대 50. 페이지 cursor는 아직 구현하지 않았습니다.
카테고리는 식품/음료/생활만 지원하고, keyword는 상품명 부분 일치 검색입니다.

## 무료배송 추천 정책 (MCP 검색의 기본값 아님)

실제 배송 규칙은 MALL 합계 50,000원 이상 무료배송, 미만 3,000원입니다.
쿠폰·적립금은 자동 사용하지 않습니다.

Agent 업무가 기본 장바구니에 대해 다음 범위를 명시적으로 검색합니다.

| 조건 | 범위/기대 후보 |
|---|---|
| 예산 미지정 | 8,000~15,000원 / P003,P004,P005 |
| 예산 30,000원 | 8,000~30,000원 / P009도 후보, 카드는 최대 3개 |
| 예산 10,000원 | 8,000~10,000원 / P003,P004 |
| 음료만 | P004,P005 |
| 예산 7,000원 | 단일 상품으로 무료배송 충족 불가 |

일반 검색 카드는 최대 5개, 무료배송 추천 카드는 최대 3개입니다.
