# 응답을 객체로 받기

이번 목표: SearchCriteria의 validate 메서드와 배송비 미계산을 이해합니다.

상품 한 개의 가격 상한과 배송비, 장바구니 합산, 주문 처리의 차이를 먼저 알아야 합니다.
null은 말하지 않음이고 0은 가격 상한 0원입니다.
오류 검사 전체 코드를 먼저 읽고, 마지막에 entity()로 객체를 받습니다.
다른 모듈을 import하지 않으며 코드 조각만 제공하는 수업이 아닙니다.

기본 흐름: 모델 응답을 entity()로 객체로 받고 접근자로 필드를 읽습니다.
값 검증은 다음 소수업에서 실제 코드와 함께 설명합니다.
실제 모델 호출에는 비용이 발생할 수 있습니다.
