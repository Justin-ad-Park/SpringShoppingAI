# {{실행 모듈 이름}}

작성 지침: 프로젝트의 실제 명령을 넣고 이 안내를 제거합니다. 이 파일만 읽어도 실행 위치와 연결 수업을 찾을 수 있어야 합니다.

## 연결된 수업과 실행 결과

관련 본문·보충 문서의 실제 링크와, 이 코드가 받는 입력·수행하는 작업·출력을 설명합니다.
공유 실습이라면 어떤 단원에서 같은 모듈을 사용하는지 밝힙니다.

## 설정 준비

실제 프로젝트의 설정 파일 위치·설정 이름·버전 확인 위치를 안내합니다.
실제 키나 개인 컴퓨터의 경로를 예제로 넣지 않습니다.

## 로컬 테스트와 빌드

프로젝트 루트 또는 모듈 루트 중 실제 작업 디렉터리를 밝히고 명령을 제공합니다.
객체별 단위 테스트와 로컬 모델 통합 테스트가 있다면 각각의 대상·클래스명과 함께 실행하는 명령을 제공합니다. 구체적인 이름은 프로젝트 설정의 기준을 따릅니다. 해당 명령의 외부 API 호출 여부를 설명합니다.

테스트 코드 설명이 필요한 경우 [학습용 테스트 기준](../rules/authoring.md#학습용-테스트)에 따라 준비·실행·검증을 혼동하기 쉬운 사례를 구분합니다. 모든 테스트에 단계 주석을 의무화하지 않습니다.

## 실제 실행

서버·프로그램 실행 명령, 입력 방법, 기대 결과와 종료 방법을 제공합니다.
가짜 서버 실행만 제공한다면 실제 서비스에 연결한 것처럼 설명하지 않습니다.

## 선택: 실제 외부 서비스 테스트

그런 테스트를 제공하는 경우에만 둡니다. 설정·실행 클래스·전체 test 포함 여부와 품질 검증의 한계를 설명합니다.

## 실행이 안 될 때

이 실습에서 자주 발생하는 증상과 실제 확인할 위치를 짧게 제시합니다.
모든 가능한 오류를 나열하지 않습니다.
