# 교육 자료 검토

1. 요청한 대상부터 검토하고, 설명의 근거나 변경 영향을 확인하는 데 필요한 참조 문서로 범위를 넓힙니다. 연결되어 있다는 이유만으로 모든 하위 문서를 읽지 않습니다. 확인한 범위를 결과에 밝힙니다.
2. 독자의 선수 지식과 단원의 목표를 기준으로 문서를 순서대로 읽습니다.
3. 관련 실행 코드·설정·테스트와 대조합니다. 실제 키나 개인 설정을 출력하지 않습니다.
4. [교육·기술 검토 기준](../rules/review.md)에서 요청·변경 유형에 해당하는 항목을 선택합니다. 사실 확인에 필요하면 해당 버전의 공식 자료를 확인합니다.
5. [검증 절차](verify-materials.md)에서 요청 범위에 필요한 읽기 전용 확인을 수행합니다. 테스트를 실행하지 않았다면 정적 검토라고 명시합니다.
6. 중요도·위치·문제·이유·개선안을 표나 목록으로 제공합니다. 항목이 여러 개면 권장 적용 순서를 안내합니다.

검토만 요청한 경우 문서·코드·설정을 수정하지 않습니다.
별도 검토 에이전트를 사용한다면 같은 결과 형식을 전달하고, 완료 후 작성자가 의견을 대조해 반영 여부를 정리합니다.
한 에이전트가 관점을 바꿔 검토한 경우 독립 검토라고 표현하지 않습니다.
