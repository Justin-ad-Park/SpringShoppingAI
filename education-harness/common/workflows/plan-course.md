# 새 과정 계획

1. 요청과 프로젝트 설정을 읽고 대상 독자·선수 지식·최종 실행 결과를 정합니다.
2. 기존 코드·자료에서 재사용할 수 있는 부분을 확인합니다. 사용자가 이미 정한 버전과 실행 방식을 우선합니다.
3. 필수 개념을 순서대로 나누고, 각 단원의 새 개념·실행 결과·확인 질문·완료 기준을 정합니다.
4. 개념 수업, 구현 수업, 선택 보충을 구분합니다. 개념 소개 단계에서 모든 고급 기술을 선수 조건으로 넣지 않습니다.
5. 단원과 실습의 대응, 공유 실습 여부와 격리 방식을 정합니다.
6. [과정 템플릿](../templates/curriculum.md)으로 계획안을 작성합니다. 다른 프로젝트라면 [프로젝트 설정 템플릿](../templates/project.md)도 채웁니다.
7. 출처는 읽을 부분·학습 시점·버전·활용 한계와 함께 안내합니다.

산출물은 계획안입니다. ‘안을 먼저’ 요청했다면 구현·전체 문서 생성으로 진행하지 않습니다.
