## 0.2.0 — 2026-11-04

- 작업을 먼저 분류하고 필요한 컨텍스트만 읽는 진입 경로, 규칙 소유 위치, 역할별 입력·권한·완료 조건을 정리했습니다.
- 행동 평가 6개와 평가 자료, 장기 작업 재개 절차·상태 템플릿을 추가했습니다. 실행 도구·교재 검증·하네스 행동 평가를 구분합니다.
- 개념·구현·보충 템플릿의 필수·조건부 항목을 나누고, 중복된 상세 규칙은 원본으로 연결했습니다.
- 프로젝트별 검사 재현 안내와 한글 제목·본문·주요 변경·검증 요약을 포함하는 현재 저장소의 커밋 방식을 반영했습니다.
- 공식 비교 근거와 검증 한계는 [구성 개선 기록](reports/2026-11-04-harness-operation-review.md)에 남깁니다. 다른 프로젝트 적용이나 새 에이전트 구성은 추가하지 않았습니다.

## 0.1.1 — 2026-11-04

- 설명의 코드 근거, 생성·구성·실행 시점 구분, 구현 대체 시 저장·실패 정책 비교, 상태가 보장하는 범위를 작성·검토 기준에 추가했습니다.
- 비교 실험의 기준 결과·재시작·재적재·관찰 경로·원복을 템플릿과 검증 절차에 연결했습니다.
- 문서 분리 후 참조·확인 질문을 확인하도록 보완했습니다. 해당 기능이 없는 수업에는 불필요한 절을 추가하지 않습니다.
- Spring AI별 호출·저장·오류·Live 테스트 확인 기준은 공통 규칙과 분리해 `project.md`에 두었습니다.
- 적용 계기와 이번 검증 범위는 [03~12장 검토 피드백](reports/2026-11-04-lessons-review-feedback.md)에 기록합니다. 다른 프로젝트에 실제 적용한 검증은 아직 수행하지 않았습니다.

- 작성·수정·교육 검토·기술 검증의 작업 절차와 결과 형식을 추가했습니다.
