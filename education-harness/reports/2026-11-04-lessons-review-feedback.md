# 03~12장 검토 피드백의 하네스 반영

작성일: 2026-11-04. 공통 버전: 0.1.1.

## 적용 범위

Spring-AI-Agent-Learning 03~12장과 하위 문서 43개를 검토하면서 발견한 19개 개선 항목을 재발 방지 기준으로 정리했습니다.
교재의 실제 수정은 커밋 `8070944`에 있으며, 이 작업은 교육 하네스만 수정합니다.
검토 사례의 기술 세부 사항을 모든 프로젝트의 필수 조건으로 가져오지 않고, 공통 원칙과 Spring AI별 확인 사항을 분리합니다.

## 적용 방식과 제한

- 원칙은 작성 규칙에, 작성 시 필요한 안내는 템플릿에, 확인 질문과 검사 방법은 검토·검증 절차에 배치했습니다.
- 저장 정책 표·실패 다이어그램은 해당 주제가 있는 수업에만 적용합니다. 모든 수업에 같은 절을 추가하거나 확인용 산출물을 별도로 만들도록 요구하지 않습니다.
- 새 검사 프로그램·CI·필수 에이전트 구성은 추가하지 않았습니다. 기존 검색·파일 비교·테스트 도구를 사용합니다.
- 기존 교재 수정이나 이전 테스트 통과 결과를 이번 하네스 변경의 실행 검증으로 다시 계산하지 않습니다.

## 검증 결과

- 하네스 Markdown의 로컬 파일·제목 앵커 링크 72개를 확인했습니다. 누락된 대상은 없으며 파일 링크는 모두 상대 경로입니다.
- `common/VERSION`과 `SOURCE.md`의 현재 공통 버전이 0.1.1로 일치함을 확인했습니다.
- `git diff --check`를 통과했습니다. 변경 범위는 하네스 문서·템플릿·버전·이 보고서입니다. 학습 교재·애플리케이션 코드는 수정하지 않았습니다.
- 한 에이전트가 작성 후 교육 관점과 기술 관점으로 순차 검토했습니다. 코드 근거·실행 시점·저장/실패 정책·상태의 범위·실험 관찰·페이지 분리가 작성 위치와 확인 절차에 연결되는지 대조했습니다.
- 문서만 변경했으므로 애플리케이션 테스트·빌드와 실제 외부 호출은 실행하지 않았습니다. 새 Mermaid 그림도 추가하지 않았습니다.
- 새 단원 제작이나 다른 프로젝트 적용을 통해 재발 방지 효과를 검증한 것은 아닙니다. 후속 교육 작업에서 이 기준을 실제로 적용하고 확인해야 합니다.
