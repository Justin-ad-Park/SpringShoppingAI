# 평가 사례와 요청 문구 정리 — 2026-11-05

공통 버전 `0.2.6`에 두 차례 검토 결과를 반영했습니다. 평가 사례를 줄이면서 이름·SOLID·JSON 등의 작성 원칙은 유지했습니다.

## 적용 내용

- 기본 E01·E02·E03·E04·E06·E07·E08·E09, 선택 E10, 과정별 E05로 구분했습니다. 매번 전 사례를 실행하지 않고 변경과 관련된 사례를 선택합니다.
- E04/E06과 E07/E08은 각각 같은 요청과 다른 입력으로 독립 실행합니다. E07도 검토 전용으로 바꿔 실제 문서 수정 대신 근거와 개선안으로 채점합니다.
- E05는 project.md로 옮기고 문맥 없는 ‘원복’을 제거했습니다. 평가 대상에게 제공할 설정 정보와 평가자에게만 제공할 합격 기준을 구분했습니다.
- E09는 변경할 이름을 미리 지목하지 않습니다. E10은 클래스 분리를 유도하는 요청과 입력 주석을 제거하고 최소 개선안이나 유지 근거를 인정합니다.
- E07 입력에서 이전 수정 당시의 세부 조건을 덜어내 목표·설명 순서·질문 불일치에 집중했습니다. E08은 예산 계산의 근거를 유지하면서 특정 프레임워크 맥락을 줄였습니다.
- E11과 json-body-builder.java.txt는 제거했습니다. 결과 구조·JSON 가독성은 기존 작성·검토 규칙으로 확인합니다. ID는 재사용하지 않고 제외 이력만 남겼습니다.
- 평가 안내·프로젝트 설정 템플릿·버전·출처를 함께 수정했습니다. 과거 보고서·출처의 당시 개수와 평가 내용은 변경하지 않았습니다.

## 검증과 한계

- 기본 8개·선택 1개·과정별 1개의 ID와 입력 8개의 대응을 확인했습니다. 문제·정상 입력 쌍의 요청 일치, 검토 전용 요청과 합격 기준, E05 이동·E11 제거, 버전 0.2.6을 정적으로 확인했습니다. 하네스 로컬 링크·앵커 130개에서 오류 0개이며 공백 검사도 통과했습니다.
- 문서와 평가 입력만 변경했습니다. 애플리케이션 소스·빌드 설정은 변경하지 않았으므로 Gradle 테스트와 외부 모델 호출을 실행하지 않았습니다.
- 단일 에이전트가 변경 자료와 참조를 순차 검토했습니다. 독립 세션 행동 평가는 선택·실행하지 않았습니다. 기본 8개·선택 1개·현재 과정별 1개는 평가 목록이며 행동 평가 통과 수가 아닙니다.
